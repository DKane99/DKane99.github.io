V6 Modules

从单页作品集，升级成真正的技术品牌站

首页只负责表达“你是谁的技术版本”。项目、笔记、代码和品牌规范全部拆分到独立页面，让站点更像一个持续生长的个人实验室。

01 · PROJECT CASES

项目详情长页

每个代表系统都有独立详情页，包含问题、架构、技术模块、工程挑战、验证逻辑与当前状态。

 02 · LAB NOTES

博客 / 实验日志

用短文记录系统思考、部署经验、调试方法与匿名技术品牌的长期维护策略。

 03 · CODE SNIPPETS

代码片段库

加入分类筛选与一键复制，让网站直接展示可复用代码，而不是只列技能名。

 04 · BRAND KIT

独立品牌资产页

集中展示 Brand Mark、Digital Sigil、Wordmark、色彩和使用规则。
05 · PRIVACY

匿名优先

不展示真实姓名、学校、公司、邮箱、手机号或证件照，仅保留公开技术人格。

06 · COMMAND UX

命令面板

按 / 或 Ctrl + K 呼出快捷导航，继续保持开发者工具式体验。
