PYTHON · VISION

检测框中心点

经常用于坐标转换、目标引导和可视化。

def box_center(x1, y1, x2, y2):
    cx = (x1 + x2) / 2.0
    cy = (y1 + y2) / 2.0
    return cx, cy
PYTHON · DEPLOYMENT

安全 FPS 统计

避免瞬时波动，让调试输出更可读。

from time import perf_counter

t0 = perf_counter()
# inference()
dt = max(perf_counter() - t0, 1e-6)
fps = 1.0 / dt
print(f"FPS: {fps:.2f}")
C++ · EMBEDDED

限幅工具

控制、PID 输出或执行机构范围保护都很常见。

template <typename T>
T clamp_value(T v, T low, T high) {
    if (v < low) return low;
    if (v > high) return high;
    return v;
}
C · EMBEDDED

简单超时判断

避免阻塞式逻辑拖死整个系统。

bool timed_out(uint32_t now,
               uint32_t start,
               uint32_t timeout_ms) {
    return (uint32_t)(now - start) >= timeout_ms;
}

  if (e.key === '/' ||

    e.preventDefault();
