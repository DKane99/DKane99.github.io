# DKane99 V6

静态多页面个人技术品牌站，无需 Node.js。

## 页面
- index.html：品牌首页
- projects.html：项目总览
- project-vision.html / project-edge.html / project-agent.html：项目详情长页
- notes.html：Lab Notes 总览
- note-*.html：独立笔记
- snippets.html：代码片段页（支持筛选与一键复制）
- brand.html：品牌系统
- 404.html：GitHub Pages 404 页

## 部署
把本文件夹内所有内容上传到 DKane99.github.io 仓库根目录即可。
